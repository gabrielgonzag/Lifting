LIFTO - SISTEMA DE XP E PR

Este documento descreve o sistema atual de XP, Iron Streak e Personal Records do LIFTO.

OBJETIVO

O XP do LIFTO representa disciplina, consistencia, intensidade, longevidade e evolucao real.

O sistema nao deve recompensar spam, login diario, PR falso ou manipulacao de carga.
O cliente exibe progresso, mas nao deve ser a fonte oficial de XP, titulos, conquistas ou PRs.

FONTE OFICIAL

Frontend:
- exibe XP, nivel, titulos e conquistas;
- mantem cache local apenas para UX;
- nao decide progressao oficial.

Supabase/backend:
- recalcula XP oficial;
- valida streak;
- desbloqueia conquistas;
- desbloqueia titulos;
- registra auditoria;
- usa dados persistidos em workout_sessions e personal_records.

SISTEMA DE PR

PR significa Personal Record.
O PR oficial representa evolucao real, performance historica e superacao.

PR nao gera XP.
PR nao altera Iron Streak.
PR nao deve virar atalho para subir de nivel.

Tipos de PR:

1. Weight PR
Recorde de carga.

2. Rep PR
Recorde de repeticoes.

3. Volume PR
Recorde de volume.

4. Estimated 1RM PR
Recorde tecnico baseado em estimativa de 1 repeticao maxima.

Formula de 1RM:
estimated1RM = weight * (1 + reps / 30)

PR OFICIAL NAO E MANUAL

O usuario pode marcar uma serie como PR na interface para destaque visual, momento favorito ou feedback pessoal.

Mas:
- isPr nao cria recorde oficial sozinho;
- PR oficial e automatico;
- PR oficial precisa bater criterios objetivos.

REGRAS ANTI-SPAM

Nao validar PR se:

- serie nao estiver completa;
- peso for menor ou igual a zero;
- repeticoes forem menores ou iguais a zero;
- repeticoes forem absurdas;
- carga for absurda;
- volume da serie for extremamente fora do padrao;
- progresso for insignificante;
- treino estiver incompleto;
- dados estiverem inconsistentes.

Limites atuais no frontend:

- peso maximo aceito para PR automatico: 500kg;
- reps maximas aceitas: 100;
- volume maximo por serie: 50000.

MARGENS MINIMAS

Weight PR em exercicios compostos:
precisa evoluir pelo menos +2kg.

Weight PR em exercicios isolados:
precisa evoluir pelo menos +1kg.

Exercicios compostos sao detectados por nomes como:
- supino;
- agachamento;
- levantamento;
- terra;
- remada.

REP PR

Rep PR so e valido se:

- as repeticoes aumentarem;
- a carga for igual ou muito proxima da anterior;
- carga atual for pelo menos 95% da carga do recorde anterior.

Exemplo valido:
80kg x 8
para
80kg x 10

Exemplo valido:
80kg x 8
para
78kg x 10

Exemplo suspeito:
80kg x 8
para
40kg x 30

VOLUME PR

Volume PR avalia:
weight * reps

Para validar novo volume de serie:
- precisa superar o recorde anterior;
- precisa ter pelo menos 3% de melhoria.

ESTIMATED 1RM PR

Estimated 1RM PR usa:
weight * (1 + reps / 30)

Para validar:
- precisa superar o recorde anterior;
- precisa ter pelo menos 1% de melhoria.

SEGURANCA

O frontend nao decide:

- XP oficial;
- PR oficial;
- titulos oficiais;
- conquistas oficiais;
- streak oficial;
- role;
- plan;
- status.

Tudo que afeta progressao, acesso, permissao ou legado deve ser validado por service/backend/Supabase.
